# 海报与正片

致敬电影《牛来》(2026) 的非官方小游戏原型。横版跑酷解谜，核心规则一句话：

> 好看的是假的，难看的才是真的。

## 玩法

- `←` `→` 移动，`空格` 跳跃，`X`（或 `J` / `Shift`）在两个世界间切换
- **海报世界（水墨）**：身轻如纸，下落被封顶可以飘行，尖刺无害；但"画上去"的平台踩不实，票根摸不到
- **正片世界（手搓 low poly）**：一切真实，平台能踩、票根能收（每张 ¥38.5）、尖刺会死
- 关卡按电影立意分三段：胆怯（教学）、担当（云雀入队指路）、直面生死（"排片消失"黑幕追逐战）
- 计分即票房：累计票房存 localStorage，凑满 **¥7705**（《牛来》上映 10 天的真实票房）解锁成就"年度最炸裂"
- 散场结算：空荡影厅座位图，观众数 = 死亡次数 + 1，配随机原创反讽五星短评

## 运行

```
python3 -m http.server 5201 --directory .
```

打开 http://localhost:5201 即可，无依赖、无构建，纯 canvas。
（Claude Code 里已配好 launch.json 条目 `niulai-game`。）

## 文件

- `index.html` 页面骨架、HUD、开场与散场遮罩层
- `game.js` 全部逻辑：物理（coyote time / 跳跃缓冲 / 分轴碰撞）、双世界渲染、关卡数据、云雀 AI、追逐战、WebAudio 手搓音效、结算

## 调试接口

控制台 `window.game`：`tp(x,y)` 传送、`sw()` 切换世界、`win()` 直达终点、`die()`、`reset()`。
